# 验证范围

运行`python -m unittest discover -s tests -v`。合成fixture只验证不同尺度、变换、样品独立编号、重复计数、状态分离、共享缺陷拒绝、移动后的复核失效、同步导出、原子恢复、缺口和Circle/FreeText实际对象修改保存重开。合成图不冒充真实锆石或专家判断。

真实案例只在本地独立测试目录重放计划、原图证据与导出；保留交付原件，公开包不放样品资料。工程通过不保证图像无裂缝、孔体或独立定位充分。没有定位预算时保留pending。

人工验收：逐页渲染主图；每个候选重新看原图及图册，尤其移动后边缘和小体；核对图册CL实径与裁框、原图行无标注、缺图明确；检查红字可读且不遮关键结构。PDF文字编辑测试同时重建AP避免逻辑值改变而屏幕显示旧值。可用支持批注的PDF编辑器分别选择Circle和FreeText；各阅读器UI能力不同不等于对象被压平。
